# Portafolio Web de JETTSUS

Bienvenido al repositorio de mi portafolio web. Este sitio ha sido desarrollado utilizando [React](https://reactjs.org/) y está diseñado para mostrar mis proyectos y habilidades como desarrollador.

## Cómo ver el portafolio

Para acceder a mi portafolio web, simplemente visita [https://jettsus.github.io](https://jettsus.github.io).

## Tecnologías utilizadas

- *React*: Utilizado para la interfaz de usuario dinámica.
- *Vite*: Herramienta de compilación rápida para desarrollo y producción.
- *Tailwind CSS*: Framework CSS para un diseño estilizado y eficiente.
- *Framer Motion*: Librería para animaciones fluidas y modernas.
- *Visual Studio Code*: Entorno de desarrollo integrado utilizado para el desarrollo del sitio.

## Cómo ejecutar localmente

- Requisitos: [Node.js](https://nodejs.org/) y [npm](https://www.npmjs.com/).
- Pasos:
  - Clona el repositorio: `git clone https://github.com/jettsus/portfolio-web-jesus.git`
  - Entra al directorio: `cd portfolio-web-jesus`
  - Instala dependencias: `npm install`
  - Inicia el servidor: `npm run dev`
  - Visita: `http://localhost:5173`

## Cómo ejecutar desde la carpeta dist

- Construye el proyecto: `npm run build`
- Sirve los archivos de la carpeta `dist`:
  - Opción 1: Usa `npm run preview` y visita `http://localhost:4173`.
  - Opción 2: Usa `npx serve -s dist` y visita `http://localhost:3000`.
  - Opción 3: Usa `npx serve -s dist -l 5173` para un puerto personalizado y visita `http://localhost:5173`.
