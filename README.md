# Portafolio Web de JETTSUS

Bienvenido al repositorio de mi portafolio web. Este sitio ha sido desarrollado utilizando [React](https://reactjs.org/) y está diseñado para mostrar mis proyectos y habilidades como desarrollador. Este repositorio contiene solo los archivos estáticos generados para su despliegue en GitHub Pages.

## Cómo ver el portafolio

Intenta acceder a mi portafolio web en [https://jettsus.github.io](https://jettsus.github.io). Si no funciona, verifica la configuración de GitHub Pages (ver abajo).

## Tecnologías utilizadas

- *React*: Utilizado para la interfaz de usuario dinámica.
- *Vite*: Herramienta de compilación rápida para desarrollo y producción.
- *Tailwind CSS*: Framework CSS para un diseño estilizado y eficiente.
- *Framer Motion*: Librería para animaciones fluidas y modernas.
- *Visual Studio Code*: Entorno de desarrollo integrado utilizado para el desarrollo del sitio.

## Cómo ejecutar localmente desde los archivos estáticos

- Requisitos: [Node.js](https://nodejs.org/) y acceso a un terminal.
- Pasos:
  - Descarga o clona el repositorio: `git clone https://github.com/jettsus/jettsus.github.git`
  - Entra a la carpeta: `cd portfolio-web-jesus`
  - Sirve los archivos:
    - Opción 1: Usa `npx serve -s .` y visita `http://localhost:3000`.
    - Opción 2: Usa `npx serve -s . -l 5173` para un puerto personalizado y visita `http://localhost:5173`.

## Configuración de GitHub Pages

- Asegúrate de que GitHub Pages esté habilitado:
  - Ve a https://github.com/jettsus/portfolio-web-jesus/settings/pages
  - Selecciona la rama `main` y la carpeta `/ (root)` o `/dist` si subiste los archivos en una subcarpeta.
  - Guarda y espera unos minutos para que se active.
- Si el sitio no se muestra, verifica que `index.html` esté en la raíz de la rama.
